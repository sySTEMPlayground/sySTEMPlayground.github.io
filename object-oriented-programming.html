Object Oriented Programming

Teacher: Kaden Zhang

Days met: 1
Time met: Coming soon!
Course length: Fall semester
Recommended grade: 6-8

this course starts with the basic definitions and keywords needed to construct a class, and then goes through more advanced intricacies of OOP. Next, students learn the structure and usage of common OOP-based datatypes. As assessments of their understanding, students complete problems and write OOP code from scratch.
This course requires basic knowledge of Java or C++ and computer science, including variables, functions, operations, conditionals, and loops.
